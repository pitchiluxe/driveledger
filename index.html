How it works

From drive totals
to individual files.

Compare two locations

Pick a drive in each pane. See total and free capacity at a glance with capacity bars that turn red at 90% used. DriveLedger measures each folder automatically. Totals appear as they are ready. Partial scans flag entries Windows skipped.

Find the biggest files

Open the largest-files view after a scan, filter by name, and jump to the containing folder. File and folder sizes use decimal GB.

Review and recycle downloads

DriveLedger checks eligible downloads before asking your local Ollama model to review the filename, size, and date. After your confirmation, Windows moves the file to the Recycle Bin.

Set up local review

Install Ollama for Windows and pull a local model. Select it in DriveLedger to review downloads. Browsing and scans work without Ollama.
